# Layered Stage 2 knowledge research

仅当 `baseline_version=layered_stage2_research_v1` 时进入隔离研究分层协议：完整阅读上述 mandatory 模块，并按回执 `layered_research_baseline_sections` 读取每个可选策略模块已经交付的原则与例外章节。`on_demand_sections` 是其余冻结原文的索引，不是已读正文。先在 Router 内明确主解释、竞争解释、候选与最强反证；凡可能改变候选是否存在、Setup 条件、禁令、结构止损或等待结论的索引章节，按精确 ID 调用 `read_allowed_knowledge` 读取完整原文再判断。若无法排除未读章节会改变结论，应读取该模块剩余相关章节，不能以节省 Token 为由猜测或忽略。该协议只用于研究对照，不是正式链路自动降权。
