# 联合 Stage 2 分层知识交付：隔离研究协议

状态：`research-only`；已完成两张真实冻结快照的四臂探索性验收。两轮质量与性能方向不一致，分层策略不晋级正式 Codex 或 VPS Paper。

## 问题与边界

2026-10-08 的真实 `gpt-6-luna/xhigh` 单 Agent 联合链耗时 324.5 秒、总计
549,761 Provider tokens；Evidence 网关约 3 秒，不是主要瓶颈。此前的无损目录/元数据
去重已证明收益有限，因此不再把几十 KB 的包装压缩当成根因修复。Stage 2 同会话续接
和完整 Router 原文是当前语义基线，正式 Job 不变。

本实验只改变**联合 Stage 2 的知识交付时机**，不改变冻结知识、Brooks Router、
Stage 1、VPA、Draft/Validator/Risk/Trader Equation 或 Direct。Host 仍发布全部已选
原文、section ID、摘要和顺序。共同规则、识别主/替代市场解释的模块完整必读；部分
策略模块首批交付前段原则及所有标题明确的例外、陷阱、反证、风险、禁止、失败、局限
章节，其余章节只在索引出现，模型必须按能否改变当前判断读取完整原文。索引不是已读
证据；不确定时读取余下相关章节。此处的标题选取是**研究交付策略**，不机械命名行情或
断言某章节不重要。

## 真实冻结行情四臂结果（2026-10-08）

同一 Binance USD-M XAUUSDT/1h 已闭盘快照，`snapshot_hash=085c385cf704eb95f7473c4c674fd1717be4e3638cf2a54f41077b3f3f9eaf5a`，

`completed_with_warnings`、等待，没有交易订单。先前环境/审计/进程中断队列的失败与缺失
原样保留，未拼接进本队列；同一快照复核不增加独立市场样本数。

盲评先于性能分析：A 组 PA/VPA 均分为 66/55，B 组为 81.5/70（0–100）；
八个预注册维度中 B 均分无一低于 A。A1 有已核实的重大 VPA 长窗方向事实错误：

B1/B2 未见同级错误。B 两例都未充分展开 K2 高活动但下行仅 0.114 ATR、
棒内 74.1% 收盘的努力/结果矛盾。盲审补核认为它们已保留相应反向回应、
接受不确定性、结构重评条件和等待禁令，尚不足以判为“遗漏会改变主判或交易许可的
最强反证”。因此 B **通过单快照探索性质量筛查**，不是统计非劣或质量提升的因果证明；
A/A 分差仍有 14 分，模型随机性不可忽略。

最终队列改用独立进程。失败队列保留，不作为模型质量或速度样本。

## VPA 串行与并行边界

当前联合链的 VPA 不是无条件的独立行情评论：Stage 1 先以 price-only 形成并验收
主/替代假设；Host 将这些假设编译为 `pa_hypotheses`；VPA 对每个假设给出量价评估，
Validator 要求恰好逐项覆盖；只有已验收报告进入联合 Stage 2。Stage 1 gate 为
wait/unknown 时还能先短路，不白花一次 VPA 模型调用。这维持 Brooks 主框架、
VPA 次级证据与唯一决策权限。

同一冻结快照下，VPA catalog、量价测量和事实索引等确定性准备可与 Stage 1
重叠，但当前这些工作不是主要时延。直接把完整 VPA 模型调用与 Stage 1 并行，
会失去当次已验收的 PA 假设和精确逐项覆盖合同，不能只改调度器。
若另做研究，可设计“无假设的量价观察 → Stage 1 完成后短的假设映射与验收”
两段式协议；比较端到端时延、Provider 累积 Token、最强反证遗漏和假设覆盖。
在质量非劣且真实延迟有足够收益之前，不改变现行串行模型链。

## 三角色自审

- **PA 交易员：** 基础决策、完整结构识别和显式例外章节常驻；其余策略案例仍可按 ID
  完读。是否因按需选择漏掉 Setup/反证不能由代码保证，必须盲评；正式链不降权。
- **Wyckoff VPA 交易员：** VPA 角色与完整已验收报告未变，联合 Stage 2 仍仅用报告
  引用，不读原始 VPA catalog、不创建第二 Router。
- **量化/软件架构师：** 研究策略由冻结身份、manifest、网关审计和 Worker 双重验收，
  源全文可重放；Direct、旧 Job、生产配置保持原样。静态投影不能证明速度或收益增量。
