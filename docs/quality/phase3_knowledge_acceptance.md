# 阶段 3：PA / VPA 知识修订与交付验收

基线：`ade4c90`（阶段 2）。范围：29 个 PA 文本、5 个 VPA 文本、知识打包/检索和 VPA 知识选择。
本报告是同一实现者的三角色自审，不是三位独立专家认证。没有部署、模型调用或收益实验。

## 结论与边界

本阶段完成知识层一致性修订、完整章节交付、持久章节标识、受控别名及版本追踪。
修订共享原知识源，Direct 和 Codex 不维护两套理论。没有删除策略模块、案例章节、反例章节或风险章节；
有误的断言原位改写，新增相反情景和适用条件，不用短摘要替代完整正文。

Brooks 仍拥有主市场框架。PA Stage 1/2 保持 price-only；VPA 仍是独立证据角色。
本阶段不启用新联合运行链路，不改 Router、materializer、Validator、Risk、Trader Equation 的执行权。
正文允许讨论反转和持仓管理理论，不表示当前产品获得逆势下单或动态管理权限。

## 稳定 ID、别名、版本与完整交付

- 原文标题后的 `<!-- knowledge: chapter-... -->` 是持久身份。改标题、移动段落时随正文一起移动，禁止重新批量编号。
- 新章节用文件内未使用过的 ID；删除章节不得将其 ID 分给新主题。显式重复 ID 拒绝打包。
- `overview` 的受控中英文别名用于发现模块；搜索返回模块/章节 ID 后可读完整模块或指定章节。
  这不是同义词模型或另一套路由，也不把 MM、Spring 等别名变成行情标签。
- 搜索只遍历当前 Frozen Job 的授权知识；别名和正文一同冻结。ASCII 短词按边界匹配，H1 不命中 H10。
- 新 bundle manifest 为 v2；模块版本、完整 SHA256、源文 SHA256、每节 SHA256 和角色选择信息绑定原有 Job digest。
- 旧冻结记录不重切片、不改 ID，仍可读取原 `#s001` 等章节。无显式锚点的自定义包兼容读取，重复标题使用 occurrence 后缀；不承诺此类旧包跨编辑稳定。
- splitter 保留标题、空白、空标题章节、代码围栏及围栏内示例；拼接全部 section text 等于原角色切片。
  搜索 snippet 是发现索引，不是完整阅读；mandatory 模块和完整读取要求没有降级。
- Stage 1/2 继续调用同一 `select_agent_knowledge_text`。未移动二元决策阶段边界；数据预检仍由 Host 替换。
- VPA 选择只读取显式 PA 周期/候选周期/pattern/climax 字段；spike 加载推进和突破接受，区间加载边界突破，
  broad_channel/三角形/双顶底补区间事件，楔形/末端/反转补高潮反证。未读成交量或自由文本决定模块。

## 核对依据

H/L 计数的间隔与再尝试、广义三推、MTR 极点测试、Measured Move 的方向性；不是将整套产品禁令归因作者。
VPA 以 [Wyckoff Analytics 方法说明](https://www.wyckoffanalytics.com/wyckoff-method/) 核对三法则与结构事件背景。
其余修订来自仓库已有框架、审查报告、当前 Draft/执行契约和多空逻辑对称检查。
保留教材案例不意味着已验证其跨资产频率；没有外部来源或匹配数据的数字不得当校准概率。
