<!-- knowledge: overview; aliases: 极速上涨交易策略 -->
【文件定位】在已确认极速上涨中，给出**顺势做多**方案（仅 SPS 回撤入场）。禁止 SCS 追尖峰、禁止追高潮、禁止逆势做空。

⚠️ **PA Agent 硬约束**：禁止 SCS/市价追尖峰、高潮后禁追多、禁止逆势、禁止仓位管理、不依赖成交量。

【核心知识】
<!-- knowledge: chapter-001 -->

一、尖峰期间允许的策略（仅 SPS）
<!-- knowledge: chapter-002 -->

**废止**：策略1 市价追尖峰、策略2 止损追突破（原 SCS）——**一律禁止**。

策略A：限价/回撤入场（SPS）
- 尖峰出现暂停或回撤后，在回撤位（38.2%–50% 或前棒低点附近）挂限价或等信号棒做多
- 须 `climax_risk=none` 或回撤已消化高潮；§10.3 通过

策略B：旗形回撤（尖峰旗形顺向突破，顺多）
- 第一次旗形整理后，顺向上突破做多（非追高潮棒）

二、尖峰到通道转换
<!-- knowledge: chapter-003 -->

尖峰后的三种发展路径按 Brooks 定性先验排序；具体权重仍由本轮暂停/回撤、跟随和结构决定：
1. 趋势恢复为通道（通常为首要假设）
2. 进入交易区间（重要竞争假设）
3. 趋势反转（证据要求最高）

以上排序不是当前品种的校准概率，禁止复制到 `estimated_win_rate`。

交易策略选择：

路径1：通道恢复（高概率）
- 识别特征：回撤后的顺向推进仍占优；深度、持续时间及重叠共同判断，不由50%划线。
- 策略：在通道下轨（趋势线）附近做多
- 止损位：顺势信号棒或回撤低点仅在其失守会否定 Setup 时作为结构候选；价格单位由程序提供
- 目标位：通道上轨或测量通道高度结构候选

路径2：进入交易区间
- 策略：仅 direction 仍偏多时在区间下沿评估做多；**禁止双边刮头皮**

路径3：可能反转
- **禁止做空**；仅 `reversal_attempt` / `mtr` 诊断 + `watch_points`
- **不输出**逆原趋势三价；`order_type=不下单`，`terminal=wait`

三、~~追单（SCS）~~（已废止）
<!-- knowledge: chapter-004 -->

**禁止**尖峰追单、市价追突破、SCS。`climax_risk≠none` 时一律 wait 或等 SPS。

四、高潮后的交易策略
<!-- knowledge: chapter-005 -->

买进高潮（统一规则，见市场诊断框架）：
- 强趋势序列 + 衰竭信号（长尾/小实体/反向棒）；**非**「2–5 根即高潮」

高潮后禁止的行为：
- 不在高潮后立即做多（买进高潮后追涨）
- 不在高潮后立即设置新的多头止损单
- **禁止**评估做空或任何逆势三价

高潮后的正确策略（单次分析）：
1. 在 watch_points 写等待回调/顺主方向 SPS 二次入场条件
2. 反转结构仅作 `reversal_attempt` 诊断，**不下空单**

五、开盘起趋势日（Opening Range Breakout）的交易
<!-- knowledge: chapter-006 -->

开盘起趋势日的定义：
- 价格在开盘后的前几根棒线内形成当天的最低点/高点
- 只能比较已知开盘区间与严格因果的历史同源日波幅；当日最终区间未知，不得用收盘后的全天高低判定。
- 开盘区间被突破后，价格朝突破方向持续运动
- 约20%的交易日属于开盘起趋势日

开盘起趋势日的交易步骤：
1. 识别开盘区间：开盘后前3-6根K线形成的价格范围
2. 等待突破：价格突破开盘区间边界
3. 确认信号：突破后至少有一根趋势棒确认
4. 入场：在突破后的回调中入场
5. 止损：开盘区间另一侧边界仅在失守会否定当前 Setup 时作为结构失效候选

开盘起趋势日的交易规则：
- 如果开盘高点在第一小时被跌破，趋势日失败
- 如果开盘低点在第一小时被突破，趋势日失败
- 趋势日确立后，回调是好的入场点
- 通常在欧美交易时段交界处最常发生

六、小幅回撤趋势日（Trend Day with Small Pullback）的交易
<!-- knowledge: chapter-007 -->

小幅回撤趋势日的特征：
- 最强的趋势日类型，一个月可能只出现1-2次
- 当天的回撤幅度仅为日均波幅的10%-30%
- 所有的回撤都是好的入场点
- 趋势棒和回调棒交替出现，呈"台阶式"上涨

小幅回撤趋势日的识别：
- 开盘后迅速形成当天的最低点
- 价格快速上涨后出现小幅回调
- 回调棒明显小于趋势棒（约30%-50%）
- 回调时间很短（1-3根棒线）
- 恢复上涨后继续创新高

小幅回撤趋势日的交易策略：
1. 首次回撤入场：在第一次明显回撤时入场
2. 每次回撤都是机会：价格每次回调到趋势线都是做多机会
3. 止损设置：最近回调低点仅在失守会否定当前延续 Setup 时作为锚点
4. 目标：结构 TP1/TP2，须 §10.3 通过

七、止损设置原则
<!-- knowledge: chapter-008 -->

止损类型1：尖峰结构止损候选
- stop 先定位当前 Setup 的结构失效；最近棒极点只是候选，不是默认替代摆动/边界的规则。
- 尖峰起点：仅当该点确为当前交易假设的失效位时，才是结构止损候选
- 止损过大则放弃；不能为了 RR 改用更宽的失效位
- 适用：3根以上标准尖峰且结构目标明确时

止损类型2：信号棒过长时重新评估 Setup
- 定位：保留当前 Setup 的真实结构失效位；风险不适合时等待、放弃，或评估另一个独立成立的 Setup
- 优点：不以缩短价格风险距离替代结构失效判断
- 反证：若较近的信号棒极点仍在正常波动内，它不能代替原失效位，也不能为凑 RR 采用
- 适用：信号棒明显过长时，核对其极点是否真的否定所选 Setup；没有独立依据则不采用

止损类型3：技术位止损
- 定位：技术位仅在被穿越会否定当前 Setup 时作为结构失效候选，不因标签自动设 stop
- 技术位：前低、趋势线、均线、斐波那契位
- 优点：反映市场结构变化
- 缺点：需要准确识别技术位
- 适用：有一定技术分析基础时

止损设置的安全规则：
- 永远不要将止损放在精确的最低价/最高价
- 缓冲示例：已确定结构失效锚点且 Host 提供真实 tick 时，可评估其外1–2 tick；这不是通用下限，不能替代结构或由模型猜测价格单位
- 止损一旦设置，不要因为害怕被扫而移动

八、利润目标设置
<!-- knowledge: chapter-009 -->

目标类型1：测量运动目标（Measured Move）
- 计算方法：从尖峰起点测量到尖峰终点
- 第一目标：测量运动的100%（等距）候选
- 第二目标：测量运动的138.2%或161.8%候选
- 约束：先明确 entry 条件与独立结构 stop，再按本轮退出协议评估 TP1/TP2；RR 只做校验，不得为了数值调整 stop
- 优点：有客观的计算依据
- 缺点：可能过于机械

目标类型2：通道高度目标
- 计算方法：测量通道的高度作为目标
- 通道高度 = 通道上轨 - 通道下轨
- 目标位 = 通道下轨 + 通道高度（或倍数）
- 适用：尖峰后进入通道的情况

目标类型3：技术位目标
- 识别前一个重要的阻力位/支撑位
- 将其作为利润目标
- 常见技术位：前高、前低、整数心理位、均线

**PA Agent 单次三价补充**（替代原「分批出场 / 逐步出场 / 连续高潮持仓管理」章节）：

- **TP1** = 近端结构目标；**TP2** = MM/通道对边等更远目标（见文件23）
- 定价顺序：entry 条件与独立结构 stop → 最近有效 TP1 → 可选独立 TP2；不得为方程反推 stop。
- TP1/TP2 与 stop 都须有独立结构依据；RR 只做校验，不能为数值移动 stop
- 程序要求 §10.3 交易者方程为正期望，不使用跨 Setup 固定 RR 下限
- **连续高潮后**：第二/第三高潮禁追原方向；在 watch_points 写等待回撤/二次入场，**不写**减仓/平仓指令

十一、~~尖峰中做空~~（已废止）
<!-- knowledge: chapter-010 -->

尖峰/高潮后**禁止做空**；仅诊断 + wait。

【实战规则 — PA Agent 单次方案】
<!-- knowledge: chapter-011 -->

规则1：仅评估 SPS 回撤做多；禁止 SCS、禁止高潮后追多。
<!-- knowledge: chapter-012 -->

规则2：止损在结构失效位外；RR 只用于校验，不能改变止损结构。
<!-- knowledge: chapter-013 -->

规则3：禁止交易：高潮后追多、假突破追多、无结构止损、多窗口严重冲突。
<!-- knowledge: chapter-014 -->

【例外与陷阱】
<!-- knowledge: chapter-015 -->

陷阱1：假突破后追多 → wait。

陷阱2：~~追单~~ → SCS 已废止，禁止追尖峰。

陷阱3：止损贴噪音 → §10.2 放弃。

陷阱4–7：（略）核心：**不逆势、不追高潮、不写仓位管理**。
- 凭感觉交易，看到上涨就入场
- 没有止损位，没有目标位
- 结果：随机亏损
- 解决：每一笔交易都必须有完整的交易计划
